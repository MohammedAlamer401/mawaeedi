# مواعيدي

تطبيق شخصي بسيط لتنظيم المواعيد والتذكير بها — Flutter، يعمل دون إنترنت، وكل البيانات في SQLite محلية على الهاتف.

لغة التصميم مأخوذة من تطبيق «نسبتي» (خط Cairo، بطاقات بحد خفيف، حقول بتسمية ثابتة، شريط تنقل سفلي، أيقونات SVG ثنائية اللون)، بألوان هوية «مواعيدي» ودعم الوضع الداكن.

## التشغيل

```bash
flutter pub get
flutter run
```

## الاختبارات

```bash
flutter test test/
```

صور الشاشات للمراجعة البصرية (بنفس أداة «نسبتي»، تُحفظ في `build/screenshots/`):

```bash
flutter test tool/screenshots_test.dart --update-goldens
```

> ملاحظة: إن تعطّل `flutter analyze` بسبب الأحرف العربية في مسار المجلد، استخدم `dart analyze`.

## البنية

```text
lib/
  main.dart                     فتح قاعدة البيانات والتفضيلات ثم تشغيل التطبيق
  app/                          التطبيق، الموجّه، الثيم (ألوان فاتح/داكن، نصوص Cairo)
  core/
    database/                   SQLite (sqflite) — جدول appointments
    notifications/              الإشعارات المحلية وتدفق طلب الإذن
    formatting/                 تنسيق التاريخ والوقت وصيغ العدد العربية
    widgets/                    مكونات مشتركة (حالة فارغة، حقول، نوافذ تأكيد، أيقونات)
  features/
    appointments/               النموذج، المستودع، المتحكم، الشاشات
    settings/                   التفضيلات وشاشة الإعدادات
    notifications/              تبويب الإشعارات: التذكيرات القادمة وما وصل، وشارة غير المقروء
    splash/  shell/             شاشة الإقلاع والتنقل السفلي (الرئيسية، مواعيدي، الإشعارات، حسابي)
```

## قواعد مهمة

- معرّف الإشعار = معرّف الموعد، فكل تعديل يستبدل الإشعار القديم ولا يكرّره، والحذف أو الإكمال يلغيه.
- عند كل تشغيل تُعاد مزامنة الإشعارات المجدولة من قاعدة البيانات، وبعد إعادة تشغيل الهاتف يعيد `ScheduledNotificationBootReceiver` جدولتها.
- إذن الإشعارات يُطلب أول مرة يُحفظ فيها موعد بتذكير، وليس عند فتح التطبيق.
- التنبيهات الدقيقة (Android) اختيارية من الإعدادات؛ بدونها قد يتأخر التذكير دقائق.

## البناء والتوزيع (مثل «نسبتي»)

`codemagic.yaml` على Codemagic:

- **android-apk** — تلقائي مع كل push على `main`: تحليل واختبارات ثم ثلاثة ملفات
  `mawaeedi-<الإصدار>-<رقم البناء>.apk` و`-arm64` و`-armv7` (الأصغر لمعظم الهواتف: arm64).
- **ios-unsigned** — يدوي: IPA غير موقّع يُثبَّت عبر Sideloadly أو AltStore.
- **ios-testflight** — يدوي، يحتاج حساب Apple Developer.

البناء المحلي على Windows: الأحرف العربية في مسار المجلد تمنع AOT؛ ابنِ من نسخة في مسار إنجليزي.
